## 运行

需要 Node.js 20 或更高版本。

```powershell
npm install
npm start
```

## 打包 Windows 安装程序

```powershell
npm run build
```

网络受限时，可使用 Windows 自带 IExpress 生成单文件安装器：

```powershell
npm run build:local-exe
```

生成无需安装、无需手动解压的单文件便携版：

```powershell
npm run build:portable
```

安装包和便携版会生成到 `dist` 文件夹。本地安装器首次运行会安装到当前用户的 `%LOCALAPPDATA%\Programs\QuickPet`，并创建桌面与开始菜单快捷方式。便携版不安装、不创建快捷方式，首次启动会在 EXE 旁的 `QuickPet-Portable-Cache` 中准备运行文件，之后直接双击同一个 EXE 即可。新版会识别旧 `%TEMP%` 缓存，并可在设置页确认清理。

## 基本操作

1. 直接按住桌宠模型并拖动即可调整位置。
2. 单击桌宠打开或隐藏快捷面板。
3. 点击“添加”输入网址，或使用“浏览”选择本地项目。
4. 也可以直接把网址、程序、文件或文件夹拖入面板。
5. 在“设置与外观”中更换桌宠图片、主题和分类。

自动散步默认开启。打开快捷面板时桌宠会停下；手动拖动桌宠后会暂停几秒，再从新位置继续活动。可在“设置与外观”中关闭自动散步或调整速度。

在“设置与外观 → 模型预览仓库”中可以保存 GLB、VRM 和 Live2D 模型。导入前会先预览并检查纹理、动作、骨骼和引用文件；旧版高光/光泽材质会在导入副本时自动转换，原始模型不会被覆盖。如果电脑不支持 WebGL，程序会自动退回 2D 模式。

静态 PNG、WebP、JPG 上传后默认自动去除背景，整个过程只在本机进行。GIF 为了保留动画暂时使用原图，不执行自动抠图。

关闭快捷面板不会退出程序。要完全退出，请右键桌宠或使用系统托盘菜单中的“退出”。

## 数据位置

开发模式下数据位于 Electron 的用户数据目录，文件名为 `quick-pet-data.json`。程序每天首次启动会自动创建本地备份并保留最近 10 份；设置页面仍可导出文件用于迁移电脑。
