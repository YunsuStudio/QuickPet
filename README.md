# 快捷宠

一只会在 Windows 桌面活动的快捷收纳宠物。把网址、程序、文件和文件夹集中到桌宠面板中，自动分类后，点击即可打开。

![快捷宠设置与外观](./docs/assets/quickpet-settings.png)

> 当前版本：`0.11.18`
>
> 支持系统：Windows 10 / 11 x64
>
> 发布形式：单文件便携版，不提供安装版

## 它能做什么

- 收纳网址、程序、文件和文件夹，支持拖放添加、自动分类、标签、收藏和最近使用。
- 通过全局搜索快速查找，也能为单个项目录制 `Ctrl`、`Alt`、`Shift`、`Win` 组合键。
- 使用 2D 图片、GIF、GLB、VRM 或 Live2D 模型作为桌宠。
- 本地自动抠取 PNG、WebP、JPG 照片主体；图片不会上传到服务器。
- 让桌宠自动散步、奔跑、观察、休息和睡觉，支持多显示器活动范围和全屏自动隐藏。
- 使用自动分类规则、剪贴板收纳、动态文件夹、提醒和多桌宠功能。
- 每日自动备份，支持损坏恢复、完整迁移和带进度的便携缓存清理。

## 界面一览

### 模型与动作

![模型预览仓库](./docs/assets/quickpet-models.png)

支持保存多只 GLB、VRM 和 Live2D 模型。导入前会检查纹理、动作、骨骼和引用文件；旧版 GLB 高光材质导致的白模会在导入副本中自动转换，原文件不被覆盖。

### 自动化中心

![自动化中心](./docs/assets/quickpet-automation.png)

自动化中心集中管理规则、剪贴板、动态文件夹、提醒和多桌宠。

### 全局搜索

![全局搜索](./docs/assets/quickpet-search.png)

默认按 `Alt + Space` 呼出。若组合键已被系统占用，程序会尝试 `Ctrl + Alt + Space`。输入 `>` 可查找设置、检查、截图、清理缓存等维护命令。

## 直接使用便携版

1. 下载 `QuickPet-Portable-0.11.18-x64.exe`。
2. 把 EXE 放进一个可写的固定文件夹，例如 `D:\QuickPet`。
3. 双击运行。首次启动会在 EXE 旁创建 `QuickPet-Portable-Cache`，无需手动解压。
4. 按住桌宠本体即可拖动；单击桌宠打开快捷面板。
5. 完全退出时，右键桌宠或使用系统托盘菜单中的“退出”。

升级时，把新版 EXE 放到原目录后运行即可。启动器会保护当前版本的数据，隔离旧运行目录，并阻止同目录旧版继续读取新版本数据。

Windows 可能因 EXE 尚未进行商业代码签名而显示 SmartScreen 提示。请只运行从本项目发布页取得的文件，并自行核对发布信息。

## 本地开发

需要 Node.js 20 或更高版本。

```powershell
npm install
npm start
```

运行测试：

```powershell
npm test
```

构建 Windows x64 单文件便携版：

```powershell
npm run build
```

产物位于 `dist/QuickPet-Portable-0.11.18-x64.exe`。构建命令只生成便携版，不生成安装程序。

## 当前限制

- 仅提供 Windows x64 便携版。
- GIF 为保留动画而使用原图，暂不自动抠图。
- 当前没有正式在线更新源，也没有商业代码签名。
- Live2D 模型必须包含完整的本地引用文件，模型使用许可由导入者自行确认。
